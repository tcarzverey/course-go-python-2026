# Dice Roller

В этом задании вам предстоит разработать CLI-утилиту для броска игральных костей, которая будет принимать различные
параметры для симуляции бросков разных типов игральных костей.

## Описание

Утилита должна принимать в качестве аргументов количество и тип игральных костей в формате `NdM`, где:

- `N` - количество костей, N <= 100
- `M` - количество граней на каждой кости, M <= 100

Например:

- `1d6` - одна шестигранная кость
- `3d20` - три двадцатигранные кости
- `2d10` - две десятигранные кости
- `37d99` - тридцать семь девяностодевятигранных костей

В случае любых ошибок во входных данных (некорректная кость/числа не укладывающиеся в ограничения/так далее), программа
должна выводить в консоль информацию об ошибке в консоль и завершаться с кодом 1.

## Флаги

Ваша программа должна параметризироваться за счет следующих опциональных флагов:

- `-n, --count <число>` - выполняет указанное количество итераций бросков, выводит информацию отдельно по каждой
  итерации
- `--seed <число>` - задаёт зерно (seed) для генератора случайных чисел; при одинаковом seed результаты бросков
  полностью воспроизводимы (подробнее см. раздел «Работа со случайностью»)
- `-s, --sum` - выводит для каждой итерации только сумму значений костей, несовместим с флагом `-v`
- `-v, --verbose` - выводит подробную информацию по каждому броску внутри итерации, а также среднее значение среди всех
  итераций, несовместим с флагом `-s`
- `-h, --help` - выводит справку по использованию утилиты

## Работа со случайностью

Чтобы броски можно было воспроизводить и автоматически проверять, работа со случайностью строго
регламентирована. Реализуйте её ровно так, как описано ниже.

- Используйте пакет `math/rand` (не `math/rand/v2` и не `crypto/rand`).
  Создайте **собственный** генератор `r := rand.New(rand.NewSource(seed))` и пользуйтесь только им;
  глобальные функции (`rand.Intn` и т. п.) использовать нельзя — их последовательность нельзя
  зафиксировать seed'ом.
- Кости бросаются в строго определённом порядке: итерации идут от первой к последней, а внутри каждой
  итерации — кости от первой (`Dice 1`) к последней (`Dice N`). Это гарантирует детерминированную 
  последовательность значений при фиксированном seed.
- Флаги `-s`/`--sum` и `-v`/`--verbose` влияют **только на формат вывода** и не меняют ни сами значения
  костей, ни порядок их генерации. При одинаковых `seed`, `N`, `M` и количестве итераций значения костей
  одинаковы независимо от флагов вывода.
- Если флаг `--seed` не указан, зерно выбирается недетерминированно (например,
  `rand.NewSource(time.Now().UnixNano())`), чтобы каждый запуск давал разные результаты.

## Примеры использования

### Бросок одной шестигранной кости

```bash
$ dice 1d6
Rolls: 4
```

### Бросок четырех двадцатигранных костей

```bash
$ dice 4d20
Rolls: 4+8+15+16=43
```

### Бросок четырех двадцатигранных костей, только сумма

```bash
$ dice --sum 4d20
Sum: 43
```

### Бросок четырех двадцатигранных костей с подробным выводом

```bash
$ dice -v 4d20
Rolling 4d20:
Dice 1: 4
Dice 2: 8
Dice 3: 15
Dice 4: 16
Sum: 43
Average: 10.75
```

### Три броска двух десятигранных костей

```bash
$ dice -n 3 2d10
Iteration 1:
  Rolls: 1+5=6
Iteration 2:
  Rolls: 8+9=17
Iteration 3:
  Rolls: 9+5=14
```

### Три броска двух десятигранных костей с подробным выводом

```bash
$ dice --count 3 --verbose 2d10
Rolling 2d10 (3 iterations):
Iteration 1:
  Dice 1: 7
  Dice 2: 3
  Sum: 10
  Average: 5
Iteration 2:
  Dice 1: 9
  Dice 2: 1
  Sum: 10
  Average: 5
Iteration 3:
  Dice 1: 5
  Dice 2: 8
  Sum: 13
  Average: 6.5
```

### Пять итераций броска трех шестигранных костей, только суммы

```bash
$ dice -n 5 -s 3d6
Iteration 1:
  Sum: 9
Iteration 2:
  Sum: 12
Iteration 3:
  Sum: 9
Iteration 4:
  Sum: 15
Iteration 5:
  Sum: 8
```

### Воспроизводимые броски с заданным seed

```bash
$ dice --seed 42 4d20
Rolls: 6+10+3+19=38
$ dice --seed 42 4d20
Rolls: 6+10+3+19=38
```

При одном и том же `seed` утилита выводит одинаковый результат при каждом запуске. Конкретные числа в
примере иллюстративны — важно, что два запуска с одинаковым seed совпадают.

### Показать справку

```bash
$ dice --help
...
```
Текст, который будет выводиться в подсказке, составьте сами
